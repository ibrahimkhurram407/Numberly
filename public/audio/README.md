Put custom voice audio files in this folder.

Folder structure:

- `public/audio/gentle/`
- `public/audio/playful/`
- `public/audio/calm/`

Supported file names:

- `count.mp3`: "Count the objects on the screen."
- `match.mp3`: "Look carefully and choose the matching number."
- `compare.mp3`: "Which side has more objects?"
- `addition.mp3`: "Add the groups together."
- `subtraction.mp3`: "Take some away and count what is left."
- `sequence.mp3`: "Find the next number in the pattern."
- `shapeCount.mp3`: "Count the shapes on the screen."
- `shapeMatch.mp3`: "Look at the shapes and choose the right answer."
- `oddOneOut.mp3`: "Find the object that is different."
- `correct.mp3`: "Great job. That is correct."
- `wrong.mp3`: "Try again. Let's look one more time."

Recommended format:

- File type: `.mp3`
- Voice: clear, slow, calm
- Length: 1 to 3 seconds
- Background music: none
- Noise reduction: yes
- Loudness: consistent across all files
